# ローカルダッシュボード実装完了のお知らせ

ご希望通り、グラフをデータごとに分離し、モダンなダークテーマのダッシュボードを実装しました！

## 実装内容
- **SQLite連携**: `src/python/calltest_vr5.py` を修正し、センサーから取得したデータを自動でローカルの `plant_data.db` に保存する機能を追加しました。
- **Webサーバー**: 軽量なPythonフレームワーク `Flask` を用いて、データを提供する `src/python/app.py` を作成しました。
- **ダッシュボード画面**: `Chart.js` を使用し、5種類のグラフ（温度、湿度、気圧、照度、土壌水分）を独立して見やすく表示するデザイン（`src/python/templates/index.html`）を作成しました。

## 起動・確認方法

以下の手順で、ローカルダッシュボードを起動できます。

### 1. 必要なライブラリのインストール
まだ Flask をインストールしていない場合は、VS Code（またはコマンドプロンプト）のターミナルで以下を実行してください。
```bash
pip install flask
```

### 2. データ収集プログラムの起動
Arduinoが接続されている状態で、以下のコマンドを実行しデータをデータベースに蓄積し始めます。
```bash
python src/python/calltest_vr5.py
```
※ 成功すると「SQLiteデータベース保存成功」というログが表示されます。

### 3. ダッシュボード（Webサーバー）の起動
**新しいターミナル（タブ）を開き**、以下のコマンドでWebサーバーを立ち上げます。
```bash
python src/python/app.py
```

### 4. ブラウザで確認
ブラウザを開き、以下のURLにアクセスしてください。
👉 [http://localhost:5000](http://localhost:5000)

グラフが1分ごとに自動更新される、美しいダッシュボードが表示されるはずです！
