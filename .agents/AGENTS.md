# プロジェクト用エージェント動作規則 (Project-Scoped Agent Rules)

このファイルは、AIエージェントが `plantcall` プロジェクトで作業する際に従うべき安全ガイドラインと規則を定義します。

## 安全ガイドラインと制約 (Safety Guidelines & Constraints)

- **ワークスペース内のアクセス制限**: すべてのファイルの読み書き、ターミナルでのコマンド実行、および操作は、現在のプロジェクトディレクトリ（ワークスペースのルートおよびそのサブディレクトリ）内に厳格に制限されます。このワークスペース外のパスにアクセスしたり、変更を加えたりしないでください。
- **破壊的操作の承認義務**: ファイルやディレクトリの削除、gitブランチのリセット、ブランチの削除、重要なファイルを削除・上書きするコマンドの実行など、あらゆる破壊的な操作は、実行前に**必ず**ユーザーの明示的な承認を得る必要があります。自動で実行しないでください。
- **事前検証・ドライランの実施**: ファイルの一括変更やシステムの構成状態を変更するコマンドを実行する前に、必ずドライラン（シミュレーション）または動作検証手順を提案してください。
- **環境設定ファイル等の安全性確保**: 外部への露出を防ぐため、指示があった場合でも `.env` ファイルやその他の認証情報ファイルを読み込んだり、編集したり、内容を出力したりしないでください。
- **ユーザー確認 (Human-in-the-Loop)**: 常にユーザーによる確認を挟むフローを維持してください。重要な手順の実行やシステム変更の前には、必ず確認と合意を得るようにしてください。
